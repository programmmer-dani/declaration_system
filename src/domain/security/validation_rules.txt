VALIDATION DOMAIN TYPES AND RULES

1. AUTHENTICATION INPUTS

username
- 8–10 characters
- starts with letter or _
- allowed: letters, digits, _, ', .
- case-insensitive uniqueness
- no spaces

password
- 12–50 characters
- at least:
  - 1 lowercase
  - 1 uppercase
  - 1 digit
  - 1 special character
- no null bytes


2. BASIC USER DATA

first_name / last_name
- required
- 1–100 chars
- allow letters (including accents), space, ' and -
- no null byte

role
- must be exactly:
  - manager
  - employee


3. EMPLOYEE PERSONAL DATA

birthday
- format: YYYY-MM-DD
- valid date
- not in the future

gender
- must be:
  - male
  - female

street_name
- required
- allow letters, digits, spaces, . ' -
- max ~100 chars

house_number
- digits only
- positive
- length 1–10

zip_code
- format: DDDDXX
- normalize: remove spaces, uppercase letters

city
- must be in predefined list of 10 cities
- case-insensitive match
- return canonical name

email
- format: something@something.domain
- max length 254

mobile_phone (input)
- exactly 8 digits
- stored as: +31-6-XXXXXXXX

id_doc_type
- must be:
  - Passport
  - ID-Card

id_doc_number
- format:
  - XXDDDDDDD
  - OR XDDDDDDDD
- uppercase

bsn
- exactly 9 digits


4. CLAIM INPUTS

claim_type
- must be:
  - Travel
  - Home Office

claim_date
- format: YYYY-MM-DD
- valid date
- NOT:
  - older than 2 months
  - more than 14 days in future

project_number
- digits only
- length 2–10

travel_distance (Travel only)
- digits only
- required if claim_type = Travel

from_zip_code (Travel only)
- same as zip_code

from_house_number (Travel only)
- same as house_number

to_zip_code (Travel only)
- same as zip_code

to_house_number (Travel only)
- same as house_number


5. MANAGER INPUTS

salary_batch
- format: YYYY-MM
- month must be 01–12


6. ADMIN / BACKUP SYSTEM

restore_code
- random string
- fixed length (e.g. 12–32 chars)
- used hashed

backup_filename
- safe filename
- no path traversal (../)
- no null bytes


7. CROSS-FIELD RULES

- If claim_type == Travel:
  travel fields MUST be present

- If claim_type == Home Office:
  travel fields MUST be NULL

- Claim edit/delete only allowed if:
  salary_batch IS NULL

- Username must be unique (case-insensitive)
